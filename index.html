¿Que es una computadora?

Es un dispositivo electronico que recibe procesa y almacena información.Nos permite trabajar,jugar y comunicarnos.

¿Qué es el hardware?

Es el conjunto de componentes físicos de una computadora, es decir,las partes que podemos tocar.

Componentes principales:

Placa base:conecta a todos los componentes.

Memoria RAM:almacena datos temporalmente.

Disco duro o SSD:almacena archivos y programas.

Tarjeta gráfica:procesa imágenes y videos.

Fuente de alimentación:proporciona electricidad.

Componentes externo:

1.Monitor: muestra la información.

2.Teclado: permite escribir.

3.Ratón: permite mover el cursor.

4.Altavoces: reproducen sonidos.

5.Impresora: imprime documentos.

6.Micrófono: permite grabar sonidos.

Tipos de dispositivo

Entrada: introducen información(teclado,ratón y micrófono.

Salida: muestran información(monitor,impresora y altavoces).

Entrada y salida: permiten ambas funciones(pantalla táctil).

¿Como funcionan juntos?

los componentes trabajan en equipo:introducimos informaciòn mediante el teclado, el procesador la procesa, la memoria RAM ayuda a trabajr con ella y el monitor muestra el resultado.

Conclusiòn

Los componentes de una computadora son esenciales para su funcionamiento.Cada uno tiene una funciòn diferente y todos trabajan juntos para permitirnos realizar distintas actividades.
